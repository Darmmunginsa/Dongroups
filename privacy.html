บริษัท ดี ออน เน็ต จำกัด ใช้ข้อมูลที่คุณส่งเพื่อประเมินงาน ติดต่อกลับ และประสานการเข้าบริการ

ข้อมูลจากแบบฟอร์ม

ชื่อ เบอร์โทร รุ่น / ยี่ห้อ UPS จำนวนเครื่อง อาการ พื้นที่รับบริการ และวันเวลาที่สะดวก หากเลือกปักหมุด จะส่งพิกัดและลิงก์แผนที่ไปพร้อมคำขอด้วย การปักหมุดเป็นตัวเลือก ไม่จำเป็นต้องเปิดตำแหน่ง

ข้อมูลส่งไปที่ใด

ในระบบเว็บไซต์จริง ฟอร์มส่งคำขอไปยังระบบ Google Apps Script ที่บริษัทกำหนด เพื่อให้ทีมงานประสานงาน ระบบหน้าเว็บเดิมอ่านผลยืนยันจากปลายทางไม่ได้ จึงไม่ถือว่าข้อความส่งออกจากเว็บเป็นการยืนยันนัดหมาย

รูปภาพและการติดต่อผ่าน LINE

ฟอร์มนี้ยังไม่รองรับแนบไฟล์ ส่งรูปฉลากรุ่นผ่าน LINE donnet2026 ได้โดยตรง ข้อมูลที่ส่งผ่าน LINE อยู่ภายใต้การให้บริการและนโยบายของ LINE ด้วย หลีกเลี่ยงภาพที่ติดข้อมูลส่วนตัวหรือข้อมูลลูกค้าที่ไม่เกี่ยวข้อง

บริการภายนอกบนหน้าเว็บ

หน้าเว็บโหลดแบบอักษรจาก Google Fonts หากเลือกเปิดแผนที่ จะโหลด Leaflet จาก unpkg และแผนที่ OpenStreetMap บริการเหล่านี้อาจได้รับข้อมูลการเชื่อมต่อตามการใช้งานของคุณ การใช้ตำแหน่งปัจจุบันต้องได้รับอนุญาตจากเบราว์เซอร์

การตรวจประกันส่งเฉพาะ Serial Number ไปยังระบบหลังบ้านของบริษัท เพื่อตรวจรายการที่อนุญาตให้ค้นหาบนเว็บไซต์ ผลค้นหาแสดงเฉพาะรุ่น วันเริ่ม และวันหมดประกัน ไม่แสดงชื่อลูกค้า ที่อยู่ หรือเอกสารการขาย

การวัดผล

เว็บไซต์ยังไม่เปิด Google tag / GTM / GA4 และไม่ส่ง event ไป Google มีเพียงจุดเชื่อมต่อสำหรับการวัดผลซึ่งปิดไว้ โดยจะไม่ส่งชื่อ เบอร์โทร อีเมล ที่อยู่ หรือข้อความที่กรอกไปใน event
